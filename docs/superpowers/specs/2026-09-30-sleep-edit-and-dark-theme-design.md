# Спецификация: Редактирование записей о сне и Тёмная тема оформления

**Дата:** 2026-09-30  
**Проект:** «My little son» (PWA трекер сна малыша)  
**Статус:** Согласовано  

---

## 1. Цели и назначение

1. **Редактирование записей о сне (Sleep Records Editing):**
   - Дать родителям возможность корректировать время начала и окончания сна, тип события (подъём, дневной сон, ночной сон), а также удалять ошибочные записи.
   - Обеспечить пересчет адаптивного расписания (прогноз следующего сна и целевой отбой) в реальном времени.
   - Синхронизировать изменения между обоими родителями через WebSocket.
2. **Тёмная тема оформления (Dark Theme):**
   - Реализовать комфортный ночной режим для использования в тёмной детской комнате без ослепления родителей.
   - Поддерживать органическую Bento Natural палитру (глубокие природно-лесные оттенки `#142017`, `#223427`, сочный лайм `#D4F27A`).
   - Предоставить мгновенный переключатель ☀️/🌙 в шапке приложения и расширенные настройки темы («Светлая», «Тёмная», «Системная») на экране настроек.

## 2. Архитектура бэкенда и API

### 2.1. Сервисный слой (`server/src/services/sleepService.ts`)

Добавляется функция обновления записи сна:
```typescript
export interface UpdateSleepEventInput {
  eventType?: 'WAKEUP' | 'NAP' | 'NIGHT_SLEEP';
  startTime?: string;      // "HH:MM" или ISO строка
  endTime?: string | null; // "HH:MM", ISO строка или null (если сон продолжается)
  napNumber?: number | null;
  date?: string;
}

export function updateSleepEvent(
  eventId: string,
  childId: string,
  input: UpdateSleepEventInput
): { event: FormattedSleepEvent; status: DayStatusResponse }
```

**Логика работы:**
1. Проверка существования записи по `id` и принадлежности к `child_id`.
2. Нормализация времени начала и окончания к ISO-формату (`normalizeToIso`).
3. Расчет `duration_minutes`:
   - Если `endTime` задан, вычисляется разница в минутах между `startTime` и `endTime`.
   - Если `endTime` отсутствует (сон продолжается), `duration_minutes` выставляется в `null`.
4. Обновление записи в SQLite через параметризованный запрос `UPDATE sleep_events`.
5. Получение обновленного статуса дня через `getDayStatus` с пересчетом расписания движком `@shared/sleepEngine`.

### 2.2. REST эндпоинты (`server/src/routes/sleepRoutes.ts`)

- `PUT /api/sleep/events/:id`
  - Авторизация: опциональный JWT токен (с привязкой к `familyId` и `childId`).
  - Вход: JSON объект `UpdateSleepEventInput`.
  - Выход: `{ event: FormattedSleepEvent, status: DayStatusResponse }`.
  - Оповещение WebSocket:
    ```typescript
    broadcastToFamily(familyId, {
      type: 'SLEEP_STATUS_CHANGED',
      payload: {
        childId,
        action: 'UPDATE_EVENT',
        eventId,
        timestamp: new Date().toISOString(),
        result,
      },
    });
    ```
- Существующий `DELETE /api/sleep/events/:id` уже реализован и рассылает `DELETE_EVENT`.

## 3. Пользовательский интерфейс и UX

### 3.1. Шторка редактирования `EditSleepModal.tsx`

Компонент всплывающей снизу шторки (Bottom Sheet):
- **Свойства (`EditSleepModalProps`):**
  - `isOpen: boolean`
  - `onClose: () => void`
  - `event: FormattedSleepEvent | DayLogRecord | null`
  - `onSave: (eventId: string, data: UpdateSleepEventInput) => Promise<void>`
  - `onDelete: (eventId: string) => Promise<void>`
- **Компоненты интерфейса:**
  1. *Драг-хэндл и заголовок:* плавное закрытие свайпом вниз или кликом по ✕.
  2. *Выбор типа:* 3 кнопки-пилюли: «Подъём», «Дневной сон», «Ночной сон».
  3. *Номер дневного сна:* для дневных снов отображается выбор номера (1, 2, 3).
  4. *Поле времени начала:* стилизованный `<input type="time">`.
  5. *Поле времени окончания:* стилизованный `<input type="time">`, скрываемый для типа «Подъём», с чекбоксом «Сон ещё продолжается».
  6. *Расчет длительности:* визуальная подсказка длительности сна (например, «1 ч 20 мин»).
  7. *Кнопка «Сохранить изменения»:* большая салатовая кнопка `#D4F27A`.
  8. *Кнопка «Удалить запись»:* предупреждающая терракотовая кнопка с двухэтапным подтверждением для предотвращения случайного удаления.

### 3.2. Точки входа для редактирования

1. **Экран «Сегодня» (`TodayAwakePage`, `TodaySleepingPage`):**
   - Список «Записи за день» (`DayLogsList`): клик по любой строке сна открывает `EditSleepModal` для этой записи.
2. **Экран «Календарь» (`CalendarPage`, `DayDetailCard`):**
   - В карточке детального дня клик по строке события в списке или кнопка «Изменить» открывает редактирование выбранного события.

## 4. Тёмная тема оформления (Dark Theme)

### 4.1. Токены стилей (`client/src/styles/theme.css`)

Определяются переменные для светлой темы по умолчанию (`:root`) и переопределения для тёмной темы (`[data-theme="dark"]`):

| Переменная | Светлая тема (`:root`) | Тёмная тема (`[data-theme="dark"]`) | Описание |
|---|---|---|---|
| `--bg-primary` | `#ECEEE6` | `#142017` | Основной фон экранов и мобайл-контейнера |
| `--color-white` | `#FFFFFF` | `#223427` | Фон основных карточек Bento |
| `--color-dark` | `#23372A` | `#1A281E` | Фон тёмных Bento-карточек (таймеры, герои) |
| `--color-neutral-bg` | `#F4F5EF` | `#1B291F` | Фон внутренних инпутов, чипсов и ячеек |
| `--color-border` | `#E3E7DA` | `#2C3F30` | Разделительные линии и границы |
| `--text-primary` | `#1E2A20` | `#F1F4EA` | Основной контрастный текст |
| `--text-muted` | `#4A5A4C` | `#A6B8A5` | Второстепенный шалфейный текст |
| `--text-subtle` | `#B7C4B4` | `#70846F` | Приглушенные подписи |
| `--color-lime` | `#D4F27A` | `#D4F27A` | Акцентный яркий салатовый цвет |
| Десктопный фон `body` | `#E2E5DC` | `#0E1711` | Внешняя подложка вокруг контейнера |

### 4.2. Хук `useTheme.ts`

- Поддерживаемые значения: `'light' | 'dark' | 'system'`.
- Сохраняет выбор в `localStorage.getItem('mls_theme')`.
- При значении `'system'` слушает медиа-запрос:
  ```typescript
  window.matchMedia('(prefers-color-scheme: dark)')
  ```
- Синхронно обновляет атрибут `<html data-theme="...">` для исключения мигания при перезагрузке.

### 4.3. UI элементы переключения темы

1. **Кнопка в `Header.tsx`:**
   - Компактная круглая кнопка с иконкой ☀️ (в тёмной теме) или 🌙 (в светлой теме), расположенная рядом со статусом «Мама · Папа».
   - Мгновенное переключение светлая ↔ тёмная в один клик.
2. **Карточка в `SettingsPage.tsx`:**
   - Bento-блок «Оформление» с тремя вариантами: «Светлая», «Тёмная», «Системная».
