## 1. Logo & PWA Branding

### 1.1 Source Assets
- Векторный логотип: `logo/logo.svg` (фон `#253729`, гармоничные золотисто-лаймовые и белые элементы спящего солнца и месяца).
- **Размещение в PWA и браузере:**
  - `client/public/icon.svg` — векторная иконка для PWA (`any`, `maskable`).
  - `client/public/favicon.svg` и `client/index.html` — favicon сайта и мобильных закладок (`<link rel="icon" ...>`).
  - Генерация/обновление `manifest.json`: имя "My little son", иконки `icon.svg` и `favicon.svg`.

### 1.2 Layout на экранах «Вход» (`LoginPage`) и «Регистрация» (`RegisterPage`)
- **Верхний блок-полоса:**
  - Над блоком с логотипом и правыми карточками (месяц/батарея) добавляется горизонтальная плашка-полоса Bento Natural.
  - Текст: **«My little sun»** (стильный акцентный шрифт, мягкое свечение или капсульный бейдж).
- **Блок логотипа:**
  - В тёмной Bento-карточке (`#23372A`), где ранее был простой текст «My little son», размещается целевой логотип `logo.svg` с деликатной подписью «режим сна малыша для всей семьи».

## 2. Кодовое слово и восстановление пароля (Password Recovery)

### 2.1 База данных и API
- В таблице `families` добавляется поле `recovery_code TEXT`:
  - При регистрации семьи передается `recoveryCode` (например, «Барсик» или «Солнышко»).
  - Регистр и пробелы нормализуются (`trim().toLowerCase()`).
- Новый эндпоинт **`POST /api/auth/reset-password`**:
  - Вход: `{ email: string, recoveryCode: string, newPassword: string }`.
  - Поиск пользователя по email -> получение семьи -> проверка `recovery_code`.
  - При совпадении хэшируется новый пароль через `bcrypt` и обновляется в таблице `users`.
  - Возврат `{ success: true, message: 'Пароль успешно обновлён' }`.

### 2.2 UI Регистрации (`RegisterPage.tsx`)
- В режиме «Создать новую семью» добавляется поле ввода:
  - Метка: **«Кодовое слово семьи»** (input type="text", placeholder="Например: Барсик").
  - Подсказка рядом: **«Используется для восстановления доступа к семье. Обязательно запомните его или сохраните — без него восстановить пароль будет невозможно.»**

### 2.3 UI Восстановления пароля (`PasswordResetModal.tsx` / `LoginPage.tsx`)
- Клик по «Забыли пароль?» открывает модальное окно:
  - Шаг 1: ввод Email и Кодового слова семьи.
  - Шаг 2: ввод нового пароля и подтверждения.
  - Кнопка «Сохранить новый пароль» -> успешный вход или возврат к авторизации.

## 3. Биометрическая аутентификация (Biometrics / WebAuthn)

### 3.1 Кнопка на странице входа (`LoginPage.tsx`)
- Рядом с большой кнопкой «Войти» (высота 56px) размещается квадратная компактная кнопка биометрии (56×56px, radius 20px, фон `#FFFFFF` / `var(--color-white)`):
  - Иконка Face ID / Touch ID / Отпечаток пальца.
  - Клик запускает проверку биометрии через `navigator.credentials.get()` с быстрым входом без ввода пароля.
  - Если биометрия еще не настроена — выводится понятная подсказка: «Сначала привяжите биометрию в Настройках».

### 3.2 Настройка биометрии в `SettingsPage.tsx`
- В карточке профиля или отдельном Bento-блоке «Безопасность»:
  - Переключатель или кнопка **«Вход по Face ID / отпечатку»**.
  - При включении запрашивается WebAuthn регистрация (`navigator.credentials.create()`) с сохранением токена в `localStorage`.

## 4. Push-уведомления о предупреждениях (Web Push Notifications)

### 4.1 Настройки в `SettingsPage.tsx`
- Bento-карточка **«Уведомления»**:
  - Переключатель: **«Push-уведомления»** (Вкл / Выкл).
  - Подпись: *«Напоминания о приближении сна, времени пробуждения и предупреждениях о перегуле»*.
  - При включении запрашивается разрешение браузера (`Notification.requestPermission()`).

### 4.2 Движок и триггеры уведомлений (`pushNotificationService.ts`)
- Если уведомления включены:
  - **«Пора спать»**: когда countdown до сна `<= 0` или подошло окно сна.
  - **«Пора будить»**: когда превышен дедлайн пробуждения (`isWakeDeadlineExceeded` или `ABNORMALLY_LONG_NAP`).
  - **«Предупреждения»**: при появлении активных предупреждений высокого приоритета (`OVERTIRED`, `FORGOTTEN_WAKEUP_TIMER`, `DAY_BUDGET_EXHAUSTED`).
- Защита от спама: уведомление с одинаковым кодом не отправляется чаще 1 раза в 15 минут.
- Использует стандартное API браузера `new Notification(...)` и Service Worker `showNotification(...)`.
