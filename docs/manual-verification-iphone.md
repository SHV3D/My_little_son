# Ручная верификация PWA / Push / Биометрии на iPhone

> Это **чек-лист для человека**, не автотест. Выполняется руками на реальном iPhone после деплоя ветки с PWA/push/биометрией на `son.shved.su`. Отмечайте каждый пункт по ходу проверки.

Требования: iPhone с iOS ≥ 16.4, Safari.

## Чек-лист

- [ ] **HTTPS-редирект.** Открыть `http://son.shved.su` — должен произойти редирект на `https://son.shved.su` (код `301`).
- [ ] **Установка на домашний экран.** Safari → «Поделиться» → «На экран „Домой"». Проверить, что сохранённая иконка — это реальная иконка приложения, а не скриншот текущей страницы.
- [ ] **Запуск с домашнего экрана.** Тап по иконке открывает рабочее приложение (не белый экран).
  - Если на старой установке показывается белый экран — это залипший старый Service Worker. Разовое решение: удалить иконку с домашнего экрана и добавить её заново. После этого белый экран не должен повторяться.
- [ ] **Включение push.** В «Настройках» приложения включить push-уведомления → должен появиться системный запрос разрешения iOS → принять. После принятия должна появиться новая строка в таблице `push_subscriptions` (проверить в БД на сервере).
- [ ] **Push при закрытом приложении.** Закрыть приложение полностью (не просто свернуть). Довести ребёнка/настройки до notifiable-состояния (например, `countdownMinutes <= 0`) и/или подождать срабатывания cron (до минуты). Уведомление «Пора спать» / «Пора будить» должно прийти, пока приложение **закрыто**.
- [ ] **Включение биометрии.** В «Настройках» включить вход по биометрии → должен появиться системный запрос Face ID → после успешного прохождения должна появиться новая запись в таблице `webauthn_credentials`.
- [ ] **Вход по Face ID.** Выйти из аккаунта. На экране входа нажать «Вход по Face ID»:
  - Успешное прохождение Face ID → вход в аккаунт выполнен.
  - Отмена запроса или попытка с другим лицом → вход **не** должен произойти.

## Важное про биометрию

Face ID / WebAuthn credential привязан к конкретному устройству (device-bound) и не синхронизируется между телефонами. Если проверку делают оба родителя — маме и папе нужно пройти пункт «Включение биометрии» и «Вход по Face ID» **каждому на своём iPhone**, записи в `webauthn_credentials` будут раздельные.
