# My little son — Умный трекер и планировщик сна ребенка1

Полнофункциональное веб-приложение (PWA) для ведения и адаптивного планирования режима дневного и ночного сна ребенка с поддержкой совместного доступа для родителей в реальном времени.

Визуальный дизайн строго соответствует концепции **Bento Natural («Лес и Шалфей»)** на базе шрифта **Geologica**.

---

## Ключевые возможности

1. **Экран «Сегодня — бодрствует»**:
   - Крупный счетчик времени бодрствования с 7-сегментной шкалой усталости.
   - Bento-карточки следующего сна, цели отбоя, прогресса сна за день и оставшихся снов.
   - Быстрое действие «Уснул» с возможностью подтверждения в один клик («Сейчас») или выбора времени со сдвигом (`−5`, `−10`, `−15`, `−30 мин`).

2. **Экран «Сегодня — спит»**:
   - Крупный счетчик текущего сна со статусом и временем засыпания.
   - Bento-карточка дедлайна подъема («Разбудить до... иначе сдвинется отбой»).
   - Пересчитанное время ночного отбоя.
   - Список записей за день с указанием автора (Мама / Папа) и кнопка добавления сна задним числом.
   - Кнопка «Проснулся».

3. **Математический движок адаптивного сна (`shared/sleepEngine.ts`)**:
   - Динамический пересчет цепочки оставшихся снов.
   - Сжатие снов при дефиците времени и выделение мостикового сна (bridge nap, от 20 мин).
   - Защита ночного сна: перенос отбоя только при невозможности уложить все сны без переутомления.
   - Проверка сходимости настроек режима (Sanity check) относительно 24-часовых суток.

4. **Экран «Календарь»**:
   - Сетка месяца с индикаторами выполнения нормы дневного сна (темно-зеленый — норма, янтарный — меньше нормы).
   - Детальный таймлайн суток (07:00–21:00) с точной визуализацией дневных снов и ночного отбоя.
   - Сводные карточки за выбранный день (длительность, отклонение от нормы, число снов).

5. **Экран «Настройки»**:
   - Редактирование имени ребенка.
   - Быстрые возрастные пресеты (3–5 мес, 6–8 мес, 9–11 мес, 12–18 мес).
   - Степлеры дневных снов, целевой отбой, интервалы бодрствования и сумма дневного сна.
   - Живой баннер сходимости графика с подсказками по балансировке режима.
   - Секция семьи с генерацией и копированием инвайт-кода (`7K4-Q9M`).

6. **Синхронизация в реальном времени (WebSocket)**:
   - Автоматическое обновление данных между устройствами родителей.
   - Индикатор присутствия («Мама · Папа» с зеленым огоньком онлайна).

7. **Авторизация и безопасность**:
   - Регистрация мамы с созданием новой семьи.
   - Подключение папы по коду приглашения.
   - Безопасное хранение паролей (bcrypt) и JWT-авторизация.

8. **PWA и мобильный UX**:
   - Манифест PWA и Service Worker для кэширования статики.
   - Поддержка автономного режима (standalone), safe-area для iOS.
   - Плавные пружинные анимации 60fps.

## Запуск проекта

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск в режиме разработки
Команда запускает одновременно бэкенд на порту `3001` и Vite-клиент на порту `5173`:
```bash
npm run dev
```
Откройте в браузере: `http://localhost:5173`

### 3. Запуск тестов
Полный набор тестов (unit, API, WebSocket, sleep engine):
```bash
npm test
```

### 4. Сборка для продакшена
```bash
npm run build
```

### 5. Автономный запуск собранного приложения
Сервер на Node.js раздает и REST API/WebSocket, и статические файлы фронтенда:
```bash
npm start --workspace=server
```
Приложение доступно по адресу: `http://localhost:3001`
